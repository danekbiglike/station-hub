# Сообщения о безопасности

Не создавайте публичный issue с ключом сопряжения, токеном аккаунта, домашним IP, записями разговоров, дампами устройства или содержимым системных файлов.

Для сообщения об уязвимости используйте [приватную форму GitHub](https://github.com/danekbiglike/station-hub/security/advisories/new). Приватные сообщения включены в настройках репозитория. Укажите воспроизводимые шаги и версию приложения; перед отправкой удалите из материалов ключи, токены, записи речи и данные аккаунта.

Обычные ошибки интерфейса и воспроизведения можно описать в [Issues](https://github.com/danekbiglike/station-hub/issues). Проект экспериментальный; не предоставляйте его сетевым портам доступ из интернета.
