# Анонс проекта

**Station Hub — звук компьютера и музыка Станции вместе.**

Можно слушать музыку Алисы и одновременно передавать на колонку звук Windows по домашней сети. Для низкой задержки есть игровой режим, а для более устойчивого воспроизведения — качественный. Небольшой виджет показывает трек Станции, обложку и состояние воспроизведения; музыку можно переключать с компьютера.

В экспериментальном режиме Алиса умеет уточнять, каким источником управлять. Проект открыт для тех, кто хочет изучить его устройство, предложить улучшения и адаптировать под свои задачи.

Пока это прототип: проверка проводилась на одной Станции первого поколения с root и компьютере Windows. Голосовой мост экспериментальный, AirPlay, Android Cast и полноценная передача видео не заявлены готовыми. Перед установкой ознакомьтесь с ограничениями и инструкциями проекта.
