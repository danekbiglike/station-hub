# Внутренние протоколы Station Hub

Это описание текущего прототипа, а не совместимый стандарт. Данные передаются по TCP без шифрования; формат может измениться. Примеры ниже используют только фиктивный ключ. Входящие длины, количество соединений и содержимое проверяются реализацией; сохраняйте эти проверки при расширении.

## Звук: порт 27361

Клиент устанавливает соединение и отправляет заголовок: ASCII `SHU2`, 16 ASCII-символов ключа, затем три 32-битных целых в сетевом порядке байтов: частота дискретизации, число каналов (1 или 2), режим (0 — качественный, 1 — игровой). Старый `SHU1` не содержит поля режима. Приёмник принимает частоту 8000–96000 Гц, сверяет ключ и создаёт Android `AudioTrack` с 16-битным PCM.

Далее каждый блок начинается с 32-битной длины в сетевом порядке. Положительная длина — PCM little-endian, выровненный по числу каналов, не более 65536 байт. Отрицательные маркеры:

| Маркер | Далее | Значение |
| --- | --- | --- |
| −1 | длина и UTF-8 JSON, до 4096 байт | название, исполнитель, время, состояние и выбор источника |
| −2 | длина и ASCII, до 128 байт | результат команды, например результат лайка |
| −3 | длина и изображение, до 131072 байт | обложка |

В обратном направлении Станция отправляет 32-битную длину и ASCII-команду до 64 байт: например `MODE:GAME`, `MODE:QUALITY`, `MEDIA:NEXT`, `MEDIA:LIKE`, `BRIDGE:ON` и `BRIDGE:OFF`. Команды не являются доказательством, что действие выполнено: результат возвращается отдельно, если он предусмотрен.

Очередь отправителя ограничена по времени. При перегрузке удаляются старые блоки, поэтому сеть не должна постоянно наращивать задержку. Потеря блоков всё равно может быть слышна; изменение размера очереди нужно оценивать и по задержке, и по устойчивости.

## Виджет: порт 27363

Запрос — одна строка ASCII `ключ команда\n`, ответ — одна строка JSON. Используются `STATE`, `PLAY`, `PAUSE`, `NEXT`, `PREV`, `SEEK <миллисекунды> <токен_трека>`, `LIKE`, `DISLIKE`, `UNLIKE`, `UNDISLIKE` с токеном трека и `VOLUME_SET <1..10>`. Состояние и команды оценок проверяют актуальность трека; команды изменения громкости проверяют известное текущее значение и ограничение увеличения одним делением. Ключ для примера имитатора: `0123456789abcdef`; реальный ключ хранится только на устройстве и у владельца.

В ответе `SENT` означает отправку запроса, а не подтверждение выполнения. Виджет ждёт соответствующего состояния и ограничивает время ожидания. Подробности голосовых запросов и `27362` доступны в `VoiceRouter.java`, `HubBridgeServer.java` и изменениях `bridge-patch/`; внутренние протоколы самой Станции не гарантированы производителем.
