# Архитектура и поток данных

Station Hub — набор независимых компонентов. Он не является официальным приложением Яндекса и не заменяет прошивку. Проверенная конфигурация: Станция первого поколения YNDX-0001 с root и Android 6, Windows-клиент и домашняя сеть. Внутренние интерфейсы Яндекса могут измениться после обновления.

## Компоненты

* `windows/native/station_hub.cpp` — Win32-интерфейс, системный трей, WASAPI loopback и отправитель PCM; Windows GSMTC даёт сведения о медиа и некоторые команды.
* `windows/native/station_discovery.cpp` и `mdns_parser.h` — ограниченный по времени локальный mDNS-поиск `_yandexio._tcp.local` по IPv4-интерфейсам. Ключ сопряжения при поиске не отправляется. Найденный адрес не заменяет введённый пользователем во время поиска и не переключает активную передачу.
* `windows/native/secure_pairing.cpp` получает ключ через ADB из `PairingProvider` и хранит его в диспетчере учётных данных Windows, привязывая к локальному идентификатору обнаруженной Станции. Ключ не записывается в файлы проекта или журнал. Android-провайдер требует `android.permission.DUMP` и проверяет UID вызывающего процесса; это не новый сетевой порт. Автосопряжение требует уже разрешённого ADB.
* `windows/native/station_widget.cpp` и `station_widget_ui.inl` — сеть и управление окном плеера. Состояние читается в отдельном потоке; `widget_layout.h` вычисляет размеры без пересечений и центрирует ограниченную группу элементов, а `widget_render.inl` выводит три оформления на единую поверхность с попиксельной прозрачностью и сглаживанием. Цветное свечение для оформления в духе Яндекс Музыки вычисляется по обложке, без копирования ресурсов официального приложения. Фон и свечение кэшируются и пересчитываются при изменении размера, цвета или оформления; данные трека и элементы управления рисуются поверх. Выбор оформления хранится в настройках виджета и применяется без перезапуска. Системные кнопки для доступности расположены за видимой областью; мышь и клавиатура обрабатываются окном. `volume_intent.h` хранит последнее желание пользователя, пока Станция не подтвердит изменение.
* `windows/native/yandex_like.cpp` — ограниченная автоматизация выбранной вкладки Яндекс Музыки через Windows UI Automation. Общего API лайка для всех плееров Windows нет.
* `android/src/ru/stationhub/app/AudioReceiverService.java` — приём и воспроизведение звука без запроса эксклюзивного аудиофокуса, экран и метаданные ПК. Соседние `Station*Monitor` считывают события Станции; `StationControlServer` отвечает на команды виджета.
* `VoiceRouter` обрабатывает ограниченные команды и передаёт часть запросов штатной Алисе. `HubBridgeServer` связывает это с экспериментальным мостом. Исходный текст произвольных разговоров не записывается самим Station Hub; не включайте журналирование на уровне моста без осознанного решения пользователя.
* `rating-service` — отдельный Go-процесс только на loopback, который работает с активным аккаунтом на Станции для чтения и снятия оценок. Учётные данные остаются в памяти процесса на устройстве; не отправляйте их клиенту ПК и не добавляйте их в логи.
* `bridge-runtime` управляет запуском и откатом экспериментального моста; `bridge-patch` содержит воспроизводимые изменения к исходному Quasar Bridge. Служба оценок может работать независимо от голосового моста.
* `windows/station_audio.py` — старый резервный отправитель и основа тестов протокола, не основной клиент. Рабочий Windows-клиент не требует Python.

## Сеть и безопасность

| Порт | Назначение |
| --- | --- |
| 27361/TCP | аудио и метаданные ПК → Станция |
| 27362/TCP | локальный интерфейс голосового моста |
| 27363/TCP | команды и состояние виджета; ключ сопряжения |
| 27364/TCP | сервис оценок; только loopback на Станции |
| 18443/TCP | экспериментальный Quasar Bridge; только loopback |
| 5353/UDP | локальное mDNS-обнаружение Станций; ответы на временный порт клиента |

Ключ — 16 шестнадцатеричных символов, созданных приложением на Станции. Он проверяется для аудио и управления, но поток не шифруется, и короткий статический ключ не заменяет защиту сети. Запрос через ADB наследует свойства безопасности уже настроенного ADB; на рутованных устройствах он может быть доступен в сети без дополнительной авторизации. Не пробрасывайте порты в интернет. Root-shell, ADB, системные порты и данные учётной записи требуют отдельной защиты. Не публикуйте ключи или сетевые адреса.

## Громкость и оценки

Значение громкости читается из событий Станции как уровень 0–10, но подтверждено только ограниченными испытаниями на одной прошивке. Изменение использует текстовую команду штатной Алисы, а не Android `AudioManager` и не обратную запись во внутренний аудиопротокол. Сервер отклоняет повышение больше одного деления за запрос. Виджет ожидает реального нового значения и сохраняет последнее выбранное значение в течение ожидания. При обрыве или тайм-ауте он возвращается к измеренному состоянию. Эта синхронизация проверена на имитаторе, а реакция конкретной прошивки требует пользовательской проверки.

Кнопки оценки активируются только когда известна оценка текущего трека и его идентификатор. Команды содержат токен трека, чтобы запоздалое нажатие не применилось к следующему. Установка оценки использует штатную команду Алисы; снятие обрабатывает сервис оценок. Состояние может приходить с задержкой.

## Голосовой мост и восстановление

Мост перехватывает ограниченные команды и может уточнять источник. Переключение адреса происходит асинхронно; завершать мост до подтверждённого возврата на штатную конечную точку опасно. На одной установке были две перезагрузки без сохранённой доказанной причины. Защитный механизм отключает следующий запуск при ранней повторной загрузке; один обычный запуск после перезагрузки проверен, но длительная стабильность и все сценарии восстановления не доказаны. `rollback-hook.sh --check` только проверяет совпадение текущего системного сценария с ожидаемым; не применяйте откат вслепую на другой прошивке.
