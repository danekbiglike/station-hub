Проверено 28 октября 2026 года. Первая публикация содержит исходники; готовые бинарные релизы в неё не входят.

- [x] Указаны автор и разработчик Danek Big Like, профиль GitHub и лицензия MIT для собственного кода проекта.
- [x] В SUPPORT.md и `.github/FUNDING.yml` добавлены ссылки на поддержку, предоставленные автором.
- [x] Сохранены происхождение, точная ревизия, LICENSE и NOTICE Quasar Bridge. Патч применяется к чистым исходникам указанной ревизии; тесты `internal/bridge` и `cmd/quasar-bridge` проходят. Сторонние зависимости не включаются в эту публикацию.
- [x] Все 78 исходных файлов проверены на ключи известных форматов, неизвестные ключи сопряжения, личные пути, реальные IPv4-адреса и запрещённые артефакты. Локальные сборки, инструменты, загрузки и данные устройства исключены.
