# Разработка и сборка

## Требования

* Windows 10/11 x64, Visual Studio Build Tools с C++ и Windows SDK. `build.cmd` ищет установленный компилятор через `vswhere` или использует активное окружение Developer Command Prompt.
* Для Android — JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Укажите `JAVA_HOME` и `ANDROID_HOME` или `ANDROID_SDK_ROOT`. Приложение рассчитано на Android 6/API 23 и выше; сборка использует API 35.
* Для Go-компонентов — Go 1.27.3 для мостовой зависимости; локальные `rating-service` и `bridge-runtime` используют стандартную библиотеку. Для необязательных тестов старого протокола нужен Python 3.
* Для установки приложения — отдельно подготовленная совместимая Станция, работающий ADB и доверенная сеть. Настоящий адрес и ключ должны оставаться локальными.

## Windows

Из корня проекта:

```powershell
cmd /c windows\native\build.cmd
cmd /c windows\native\test.cmd
```

Получается `windows/native/build/StationHub-next.exe`. Сборка не перезапускает текущую копию. Закройте действующее приложение обычным способом перед заменой `StationHub.exe`; сделайте резервную копию и учтите, что передача звука при замене прервётся.

`test.cmd` проверяет также разбор mDNS-ответов, указатели сжатия и повреждённые пакеты. Он собирает `windows/native/build/discovery-probe.exe`, но не запускает его: отдельный запуск отправляет mDNS-запрос в локальные сети и выводит найденные IPv4-адреса, поэтому не публикуйте его вывод без очистки личных адресов. Поиск не передаёт ключ подключения и не сканирует все адреса подсети.

Для работы в имитаторе в одном терминале запустите `go run tests/mock_station.go`, в другом задайте переменные и откройте собранное приложение:

```powershell
$env:STATION_HUB_HOST = '127.0.0.1'
$env:STATION_HUB_KEY = '0123456789abcdef' # только фиктивный ключ имитатора
& .\windows\native\build\StationHub-next.exe
```

Имитатор не передаёт звук и не подключается к Станции. При нажатии регулятора он имитирует задержку подтверждения и печатает только выбранное тестовое число. Для независимых настроек окна можно задать тестовый `LOCALAPPDATA` только в процессе клиента. Не запускайте две копии с передачей на одну колонку одновременно.

## Android

```powershell
./build.ps1
```

Скрипт создаёт `build/station-hub-aligned-debugSigned.apk`, подписанный стандартным локальным debug-ключом Android из профиля разработчика, и проверяет подпись. Debug-ключ и `build/` не предназначены для публикации. Для обновления уже установленного пакета нужна совместимая подпись; при несовпадении Android отклонит установку. Не удаляйте установленный пакет автоматически: это удалит его локальный ключ сопряжения.

На уже подготовленном устройстве можно установить APK через `adb install -r`, затем открыть `ru.stationhub.app/.MainActivity`. Точное подключение ADB зависит от способа получения root. С экраном можно ввести показанный ключ вручную; без экрана Windows-клиент запрашивает `content://ru.stationhub.app.pairing/key` через уже разрешённый ADB. Провайдер доступен shell/root UID и самому приложению, но не обычным Android-приложениям. Не включайте вывод запроса или сам ключ в сообщения об ошибках.

После `build.ps1` проверку ограничений провайдера можно выполнить на локальном Android-эмуляторе: `./tests/test_pairing_provider.ps1 -Serial emulator-5554`. Скрипт создаёт два отдельных тестовых пакета, проверяет доступ shell и отказ обычному приложению, а затем удаляет только созданные тестовые пакеты. Для физического устройства требуется явный флаг `-AllowDevice`; существующие пакеты с тестовыми именами не перезаписываются. `test.cmd` дополнительно проверяет запуск фиктивного ADB и сохранение/удаление временной тестовой записи в диспетчере учётных данных Windows.

## Службы Go

```powershell
$env:GOOS='linux'; $env:GOARCH='arm64'; $env:CGO_ENABLED='0'
go build -o build/voice-pilot ./bridge-runtime/main.go
go build -o build/rating-service ./rating-service/main.go
Remove-Item Env:GOOS, Env:GOARCH, Env:CGO_ENABLED
$env:GO111MODULE='off'
go test ./bridge-runtime ./rating-service
Remove-Item Env:GO111MODULE
python -m unittest discover -s tests -p 'test_*.py'
```

Готовая команда установки этих служб для произвольной прошивки пока отсутствует. `rating-supervisor.sh` ожидает исполняемый `rating-service` и локальный набор сертификатов `rating-ca.pem` в `/data/local/stationhub-bridge`; автозапуск также зависит от доступа root и условий прошивки. Не копируйте автоматически сертификатные наборы или содержимое системных каталогов из чужой установки.

## Quasar Bridge

Клиент для уточнения источника требует изменённой версии Quasar Bridge. Изучите `bridge-patch/README.md`, примените патч к указанной ревизии в отдельной папке и запустите тесты до сборки. Мост и соответствующие системные сценарии — эксперимент: для них пока нет универсального безопасного установщика. Исходные файлы конкретной колонки, её системный сценарий и конфигурация не включены в проект. Не применяйте `install-hook.sh` к новой прошивке без изучения его действий, резервной копии и отдельного плана восстановления.

## Отладка интерфейса

Геометрия в `widget_layout.h` должна оставаться корректной при минимуме 330×110, широком и высоком размере. `test.cmd` проверяет каждый размер до 1600×1000 на выход за границы и пересечение элементов, а также скруглённую обложку и сценарий громкости. Визуальную проверку при перетаскивании это не заменяет. При изменениях проверяйте скругление, состояния кнопок, перерисовку во время перетаскивания, работающую клавиатуру и настройки закрепления. Не используйте реальные команды громкости для автоматических визуальных тестов. После изменений сценария громкости проверяйте последовательность «1 → 2 → 1» в имитаторе.
